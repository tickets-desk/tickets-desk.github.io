# TICKETS UA — Agent Dashboard

Внутрішній веб-інструмент для операторів підтримки та авіа-агентів Tickets UA.

## Можливості

1. **Довідник Manage Booking (64+ АК)**:
   - Швидкий пошук за назвою або IATA-кодом
   - Прямі посилання на кабінети Manage Booking та Онлайн-реєстрацію (Check-in)
   - Закріплення обраних авіакомпаній (★ Favorites)
   - Персональні нотатки оператора для кожної АК
   - Можливість додавати власні авіакомпанії

2. **Скрипти й шаблони (23+ шаблони)**:
   - Поділ за категоріями (Багаж, Місця, Зміни, Запити партнерам)
   - Швидкі клавіатурні скорочення `::` (наприклад `::can` для скасованих, `::20k` для 20кг багажу тощо)
   - Інтелектуальна система плейсхолдерів (`[PNR]`, `[FLIGHT]`, `[DATE]` тощо)
   - Попередження жовтим кольором, якщо залишився незаповнений плейсхолдер
   - Двомовний редактор (UA / EN) із живим автоматичним перекладом на льоту
   - Можливість створення та редагування власних шаблонів

3. **Парсер альтів (Alt Parser via OCR)**:
   - Вставка скріншоту прямо з буфера обміну (`Ctrl + V`)
   - Локальне розпізнавання тексту (Tesseract.js v5 WebAssembly)
   - 100% точне вилучення дати, рейсу, часу та маршруту (Місто – Місто)
   - Форматування в один рядок для миттєвої відправки в чат або партнеру

## Безпека та архітектура

- **Frontend-only (Zero Server Vulnerabilities)**: Немає бекенду чи відкритої бази даних, які можна було б скомпрометувати чи зламати.
- **Повна ізоляція даних**: Усі персональні зміни кожного оператора (додані шаблони, нотатки) зберігаються виключно в локальному `localStorage` його браузера.
- **Конфіденційність пасажирів**: OCR розпізнавання скріншотів виконується локально в браузері оператора. Зображення нікуди не завантажуються.
- **Прихована панель розробника**: Доступ за секретною комбінацією `Ctrl + Shift + D` та PIN-кодом (`2026`).
